# Nihongo Dōjō

Apprentissage du japonais pour francophones, de zéro jusqu'au niveau JLPT N5.

Site en ligne : https://kirgnaar.github.io/Nihongo/

## Contenu

- Hiragana et katakana (46 + 46), dakuten et combinaisons
- 104 kanji du JLPT N5 : sens, lectures, exemples
- 10 leçons progressives : dialogues, vocabulaire, grammaire
- Grammaire de référence : particules, conjugaisons, comparatifs, compteurs
- Quiz corrigés avec explications

## Utilisation

Ouvrez le site dans un navigateur, aucune installation. Interface entièrement
en français, aucune dépendance externe. La progression est enregistrée
localement dans le navigateur.

## Structure du dépôt

- `index.html` : l'application complète
- `Annexe/` : documents de référence et archive de la version initiale
